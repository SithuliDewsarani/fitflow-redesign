# FitFlow Technology Stack Summary

## Frontend
React Native is selected for mobile development because it provides
cross-platform development, code reusability, fast development,
and near-native performance.

React is used for the web application.

## Backend
Node.js with NestJS is selected for the main backend because it
supports scalable APIs and real-time application features.

Python with FastAPI is used as a separate AI microservice.

## Database
PostgreSQL is used for structured application data.

Firebase / Firestore supports real-time social features and
notifications.

## Authentication
Firebase Authentication is used for secure cross-platform
user authentication.

## AI/ML
TensorFlow Lite and cloud-based AI services support personalized
workout recommendations and nutrition recognition.
