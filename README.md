

# FitFlow Redesign

FitFlow is a redesigned fitness tracking application developed as part of
IT3060 – Human Computer Interaction, Lab Exercise 05.

## Project Overview

The FitFlow redesign focuses on improving the user experience through
AI-powered personalized workout plans, social community features,
improved nutrition tracking, and secure user data management.

## Main Features

- AI-powered personalized workout plans
- Social and community features
- Nutrition tracking
- Camera-based food recognition
- Progress dashboards
- Real-time notifications
- Secure authentication
- Offline support

## Technology Stack

### Frontend
- React Native – Mobile application
- React – Web application

### Backend
- Node.js / NestJS – Main backend API
- Python / FastAPI – AI microservice

### Database
- PostgreSQL – Structured application data
- Firebase / Firestore – Real-time features

### Authentication
- Firebase Authentication

### AI/ML
- TensorFlow Lite
- Cloud-based AI services

## Project Structure

- frontend/ – Mobile and web frontend applications
- backend/ – Main backend services
- ai-service/ – AI and machine learning services
- docs/ – Project documentation

## Documentation

The docs folder contains:

- Technology comparison matrix
- Technology stack summary
- High-level architecture
- Architecture Decision Record (ADR)

## Security

The system uses secure authentication, encrypted communication,
role-based access control, and secure handling of sensitive user data.
